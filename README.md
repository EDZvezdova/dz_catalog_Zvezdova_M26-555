# Catalog_analysis.py — ДЗ Zvezdova M26-555

Отчёт по каталогу фильмов с анализом рейтингов, длительности и жанров. Проект подготовлен для сдачи: код соответствует стилю PEP 8 (проверка через `ruff`), запускается на чистом окружении.

## Возможности

- Расчёт среднего рейтинга и статистики по длительности.
- Вывод топ‑3 фильмов по рейтингу.
- Статистика по жанрам.
- Нормализация названий и конвертация длительности (минуты → часы/минуты).
